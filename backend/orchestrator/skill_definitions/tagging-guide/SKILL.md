# Tagging Guide

Use this guide when searching for information to leverage the tag system effectively.

## Tag System Overview

Events and documents are tagged with a two-level hierarchy:

1. **Major tags** - Broad life categories (e.g., Finance, Health, Work)
2. **Minor tags** - Specific topics within categories (e.g., mortgage, prescription, project)

The available tags are provided in the "Tag taxonomy" context message. Always refer to that for the current list.

## When to Use Tags

Use tags to narrow searches when:

- The user asks about a specific life domain ("my health records", "work documents")
- The semantic query alone might return too many unrelated results
- You need to filter by category rather than specific keywords

## Tag Selection Strategy

1. **Identify the domain** - What area of life does the question touch?
2. **Check for keyword cues** - Match user's words to the keyword hints in the tag taxonomy
3. **Use major tags for broad searches** - When unsure, a major tag is safer than guessing a minor one
4. **Combine tags for cross-domain queries** - Some topics span categories (e.g., "work visa" spans Work + Legal)

## Examples

| User Question | Suggested Tags | Reasoning |
|--------------|----------------|-----------|
| "Find my tax documents" | Finance | Clear financial domain |
| "When was my last doctor visit?" | Health | Medical context |
| "Show me the lease agreement" | Living, Legal | Housing + contract |
| "What did we discuss about the project?" | Work | Professional context |
| "Find my passport" | Legal | ID/immigration documents |

## Tips

- Don't over-filter: If unsure, rely on semantic search without tags
- Tags are case-insensitive in searches
- Multiple tags act as OR filters (matches any of the tags)
- The tag taxonomy is dynamically provided - don't assume specific tags exist
